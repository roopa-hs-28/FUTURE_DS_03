# MARKETING FUNNEL & CONVERSION PERFORMANCE DASHBOARD

## 📌 Objective
To analyze customer journey and conversion performance using a marketing funnel approach.

## 🛠 Tools Used
- Power BI
- Excel

## 📊 Key Insights
- 40% of visitors convert to leads
- 50% leads become signups
- Only 6.5% convert to purchase
- Highest drop at lead stage

## 📈 Dashboard Highlights
- Funnel chart for conversion stages
- Donut chart for distribution
- Bar and line charts for comparison
- KPI card for total users
